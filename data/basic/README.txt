《棋盘上的虫子》基础版数据说明
================================

约束：
  1 <= n,m <= 100
  1 <= s <= 100
  1 <= t <= 100
  0 <= k <= 100

输入格式：
  第一行 n m
  第二行 x1 y1 x2 y2
  第三行 s k t

输出格式：
  YES ans
  或
  NO

文件：
  01.in / 01.out ... 30.in / 30.out
  manifest.tsv  每个测试点的说明和预期答案

测试点说明：
  01~20  手工构造：A=B、一维、贴边、s 不够、k=0、t 过大、
          窄棋盘死区、行/列只有一个方向需要走等。
  21~30  随机/综合数据。

标程：
  ../../src/basic/basic_bfs.cpp

生成脚本：
  ../../tools/gen_basic.py
