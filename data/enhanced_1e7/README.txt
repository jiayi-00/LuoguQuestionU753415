《棋盘上的虫子》加强版（n,m <= 1e7）数据说明
==================================================

总约束：
  1 <= n,m <= 1e7
  1 <= s <= 2e7
  1 <= t <= 1e9
  0 <= k <= 1e9
  1 <= x1,x2 <= n
  1 <= y1,y2 <= m

时间限制：2 秒
内存限制：256 MB

子任务：
  01~03：n,m <= 100，s <= 100，t,k <= 100
  04~06：n,m <= 1e5，s <= 2e5，t,k <= 1e9
  07~10：n,m <= 1e7，s <= 2e7，t,k <= 1e9

测试点：
  01  A=B，最小棋盘
  02  样例 1
  03  一维，一步跨到
  04  最大曼哈顿距离，s 刚好够
  05  中间区，两跳返回
  06  t 大于棋盘最大位移，无路可走
  07  最大棋盘，t=1, k=0
  08  大棋盘，一步 5e6
  09  大棋盘中间区，s 比答案少 1
  10  k 极大，一步跨到

文件：
  01.in / 01.out ... 10.in / 10.out
  manifest.tsv

标程：
  ../../src/enhanced_1e7/enhanced_1e7.cpp

数据生成脚本：
  ../../tools/gen_enhanced_1e7.py
