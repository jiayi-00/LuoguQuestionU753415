《棋盘上的虫子》1e9 版本数据说明
================================

约束（按题面 100% 数据）：
  1 <= n,m <= 1e9
  1 <= s <= 1e9
  1 <= t <= 1e9
  0 <= k <= 1e9

输入格式：
  第一行 n m
  第二行 x1 y1 x2 y2
  第三行 s k t

输出格式：
  YES ans
  或
  NO

文件：
  01.in / 01.out ... 05.in / 05.out
  manifest.tsv  每个测试点的区域、参数、答案和说明

标程：
  ../../src/1e9/math_1e9.cpp   （O(1)，三个区统一，见 ../../src/1e9/solve1e9.hpp）

对拍程序：
  ../../src/1e9/verify_1e9.cpp  （并查集区间 BFS 作参考，已对拍约 590 万组）

五个测试点的设计
----------------
01  中间区，k=3 极小，s=L-2t=2。
    这是最难的形态：每两步只能漂移 3 格，答案 ~2.7e8，
    靠"一次攀爬 + 一次换层"才能取到。
    行：f(1e9,1,3e8)=133333335
    列：f(1e9,1,2e8)=133333334

02  窄棋盘边界 L=2t=8e8，且 s 恰好等于答案 16。
    行 / 列都是同区 4e8 的距离，q=min(k,L-t-1)=1e8，
    各需 2*ceil(4e8-1 / 1e8)=8 步 => YES 16。
    s 只要少 1 就是 NO，用来卡边界。

03  两个维度都是宽棋盘（2t+k=4e8 <= 1e9），答案等于无边界最优。
    行 777777776 = 3 步（每步 <=3e8，2 步最多 6e8 不够）
    列 123456788 = 1 步
    => YES 4

04  混合：行是宽棋盘（L=1e9），列是中间区（L=3.9e8，s=1.9e8）。
    行 599999999：1 步最多 3e8，2 步可覆盖 => 2 步
    列 99999999 < t，只能 2 步（1 -> 2e8..3e8 -> 1e8）
    => YES 4

05  窄棋盘死区。L=9e8，t=5e8 => M=L-t=4e8，死区 (4e8, 5e8]。
    终点 b=4.5e8 落在死区里：没有任何位置能一步跳到它，
    所以行方向永远不可达，答案是 NO（哪怕 s=1e9）。

使用建议
--------
- 01 / 05 是"卡算法"的点：10^7 的区间 BFS 做不了，纯数学分段的窄/宽公式也做不了；
- 02 卡边界（L=2t 与 s=ans 同时卡）；
- 03 / 04 用来确认宽棋盘公式和混合情况没退化。
