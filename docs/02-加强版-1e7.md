# 加强版研究：一维棋盘的三段结构

> 历史文档：本文记录 1e7 版本。全 1e9 的最终 O(1) 方案见 [04-1e9-算法](04-1e9-算法.md)。

## 1. 问题拆分

原题答案为：

```text
f(n, x1, x2) + f(m, y1, y2)
```

其中 `f(L,a,b)` 是一维问题：长度 `L`，从 `a` 到 `b`，每步 `d ∈ [t,t+k]`，不能越界。

一维问题按 `L` 与 `t,k` 的关系分成三段：

```text
窄棋盘：   L <= 2t
宽棋盘：   L >= 2t + k
中间区：   2t < L < 2t + k
```

目前已经解决前两段，第三段是完整加强版的真正难点。

---

## 2. 窄棋盘：L <= 2t

令：

```text
M = L - t
q = min(k, M - 1)
```

分为左区 `1..M`、右区 `t+1..L`，中间 `M+1..t` 是死区。
把右区位置 `p` 映射成 `p-t`，两侧都变成 `1..M`。

一次移动：

- 左区 `x` 只能到右区 `z ∈ [x, min(M,x+q)]`
- 右区 `z` 只能到左区 `x ∈ [max(1,z-q), z]`

所以每两步最多让映射坐标变化 `q`。据此可 O(1) 求 `f`。

实现：`../src/math/math_narrow.cpp`。

---

## 3. 宽棋盘：L >= 2t + k

结论：

> 当 `L >= 2t+k` 时，棋盘边界不影响一维最短步数，可以直接用无边界模型。

阈值是紧的：`L = 2t+k-1` 时已经能构造出边界导致多走一步的反例。

### 3.1 无边界模型

从 0 到 `D`，每步长度在 `[t,t+k]`，方向任意。

设：

- `m`：向右比向左多的步数
- `q`：往返对的组数

则总步数 `m+2q`，净位移可以覆盖：

```text
m*t - q*k  <=  D  <=  m*(t+k) + q*k
```

于是对固定的 `m`，最少需要的 `q` 是：

```text
q(m) = max(
    0,
    ceil((m*t - D) / k),
    ceil((D - m*(t+k)) / k)
)
```

`m+2q(m)` 是分段线性的，最小值只需检查 `D/t` 和 `D/(t+k)` 附近 O(1) 个 `m`。

`k=0` 时特判：`D` 必须是 `t` 的倍数，答案为 `D/t`。

实现：`../src/math/math_wide.cpp`。

### 3.2 为什么 L >= 2t+k 后边界不重要

证明思路：

- 取一条无边界最优走法；
- 把所有正步、负步重新配对，可以让整条走法的活动区间长度不超过 `2t+k`；
- 若活动区间超过 `2t+k`，说明存在一次“多余”的往返，可以调整或删去，与最优性矛盾；
- 因此只要棋盘至少 `2t+k` 个格子，就能把这条最优走法放进棋盘。

这个结论已对 `t<=20, k<=10`、`L<=80` 的小范围全部暴力验证；并且 `L=2t+k-1` 有反例，所以阈值不能更小。

---

## 4. 中间区：2t < L < 2t+k

这是还没有完全解决的一段。

最小反例：

```text
L=7, t=3, k=2, a=3, b=5
```

- 无边界答案是 2；
- 棋盘内真实答案是 3；
- 两条无边界 2 步走法都需要超出棋盘：`3 -> 8 -> 5` 或 `3 -> -2 -> 5`。

这说明宽棋盘公式在这一段不能直接用。

目前能确定的是：

- 窄公式不能直接用；
- 无边界公式也不能直接用；
- 这一段需要额外的“边界折叠/区间 glue”处理。

如果加强版要覆盖这一段，需要继续研究。

---

## 5. 建议的加强版定义

建议先出一个数学上干净、样例也满足的加强版：

```text
1 <= n,m <= 1e9
1 <= s <= 1e9
1 <= t <= 1e9
0 <= k <= 1e9
保证 min(n,m) >= 2t + k
```

这样：

- 两个维度的 `L` 都满足 `L >= 2t+k`；
- 直接套无边界公式；
- 时间复杂度 O(1)；
- 现有两个样例都满足条件：
  - 样例 1：`min=10, 2t+k=5`
  - 样例 2：`min=5, 2t+k=4`

注意：这个条件不是原题的完整范围，而是“宽棋盘加强版”。完整范围还需要解决中间区。
