# 中间区研究记录：2t < L < 2t+k

> **更新（2026-11-14 23:40）**：中间区已经解决，不再需要 `L<=2e6` 的兜底。
> 新做法是"二层攀爬 + 换层"模型，纯 O(1)，见 [1e9 算法研究](04-1e9-算法.md) 与 [solve1e9.hpp](../src/1e9/solve1e9.hpp)。
> 本文保留作为研究过程记录（规律 A/B/C、固定 p,q 的反例等仍然有效，只是不再是主线）。

## 1. 中间区为什么难

一维问题按 `L` 分三段：

```text
窄：L <= 2t
中：2t < L < 2t+k
宽：L >= 2t+k
```

窄、宽都有 O(1) 公式。中间区两个公式都不能直接用。

最小反例：

```text
L=7, t=3, k=2, a=3, b=5
```

无边界最优 2 步：

```text
3 -> 8 -> 5
3 -> -2 -> 5
```

两条都出界，棋盘内真实答案是 3。

---

## 2. 两条实验规律

对小范围做了完整 BFS 对拍，并随机测试了 `t,k <= 150` 的 20000 组，发现：

### 规律 A：固定 p,q 的可达位置是一个区间

固定“向右 p 步、向左 q 步”，在 `[1,L]` 内能到达的位置集合是一个连续区间 `[lo,hi]`。

因此固定 `p,q,D` 的有界判定可以转成算 `lo(p,q)` 和 `hi(p,q)`。

区间 DP：

```text
S[0][0] = [a,a]

S[i][j] =
    (S[i-1][j] + [t,U])      // 最后一步向右
  ∪ (S[i][j-1] - [t,U])      // 最后一步向左
  再与 [1,L] 取交
```

其中 `U=min(t+k,L-1)`。

问题是：`p,q` 可以到 `1e9`，这个二维 DP 不能直接跑。

### 规律 B：中间区最多比无边界多 2 步

记无边界最少步数为 `U`，棋盘内答案为 `f`。实验范围内始终有：

```text
U <= f <= U + 2
```

- 小范围穷举没有找到 `f-U >= 3`；
- 20000 组随机 `t,k<=150` 也没有找到；
- `U` 步对应的可行 `p` 在实验范围内唯一；
- `U+1`、`U+2` 对应的可行 `p` 只有很少几个。

如果这条规律能证明，中间区就变成：

```text
先试 U 步，不行试 U+1，再不行 U+2
```

但每次“试”仍需要一个高效的有界判定。

### 规律 C：候选步数处，多出来的步数很少

在 `U、U+1、U+2` 的可行 `p` 中，实验发现：

```text
要么 |p-q| <= 2
要么 min(p,q) <= 2
```

也就是说，真正难的情况只有：

- `m = p-q ∈ {0,1,2}`：多走 0~2 步向右；
- 或者 `q = p` 很小：向左步数只有 0~2 步。

配合规律 A，`p=q` 的区间已经有 O(1) 公式，所以剩下的只是“把 1~2 个额外步插入往返序列”的优化。

这个插入位置目前还没找到稳定的 O(1) 贪心；简单三分会在端点/非法区间上出错，需要继续推。

## 3. 固定 p,q 的判定：目前没有简洁闭式

已尝试的充分条件：

1. **单向块条件**
   - 先 q 步左、再 p 步右：
     存在 `N ∈ [qt,qU]`，使 `N<=A` 且 `N+D ∈ [pt,pU]`；
   - 先 p 步右、再 q 步左：
     存在 `P ∈ [pt,pU]`，使 `P<=R` 且 `P-D ∈ [qt,qU]`。

2. **容量条件**
   ```text
   P ∈ [pt,pU], N ∈ [qt,qU], P-N=D
   P <= R+N, N <= A+P
   ```

这些条件都不充分。甚至“最多一次转向”的路径也不够：

```text
L=4, t=1, k=0, a=1, p=4, q=1
```

最优需要走 `右、左、右、右、右`，中间用一次左步回到底部再继续向右；
单纯“先左后右”或“先右后左”都达不到最优。

反例：

```text
L=4, a=1, b=3, p=2, q=2, t=2, k=1, U=3
```

- 无边界范围包含 `D=2`；
- 容量条件也满足；
- 但实际 `D_max=1`，走不到 3。

原因：`P=6,N=4` 迫使两步右都走 3，两步左都走 2，排不出合法顺序。

## 4. 目前能落地的中间区精确做法

如果 `L` 不太大（例如 `L<=2e6`），可以直接对一维做区间 BFS：

- 每个位置只入队一次；
- 用并查集维护“下一个未访问位置”；
- 从 `x` 枚举两段区间 `[x-U,x-t]` 和 `[x+t,x+U]`，整段删除；
- 复杂度 `O(L α(L))`。

实现见 `../src/experimental/middle_bfs_1d.cpp`。

它可以在 0.4 秒左右跑完 `L=1e7, t=1, k=0`，也可以正确算中间区。
大致内存：`nxt + dist + queue` 三个 int 数组，`L=1e7` 约 120 MB。

---

## 5. 结论

中间区的完整 `1e9` 闭式公式还没有拿到。目前有两个选择：

1. **把中间区做成 `L<=2e6` 的子任务**，用区间 BFS，稳定可写；
2. **继续研究固定 p,q 的 `lo/hi` 快速算法**，这是打通全 `1e9` 的关键。

在全范围公式没有证明前，不建议把 `2t<L<2t+k` 且 `L` 到 `1e9` 的数据放进 100%。
